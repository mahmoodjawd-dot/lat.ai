Get the Chrome extension

The extension opens these same Clickys in Chrome's right-side panel and points at things directly on the page you're browsing, with no screen sharing needed.

  1. Download this project and run npm run build:extension.
  2. Open chrome://extensions, turn on Developer mode, click Load unpacked and choose the extension folder.
  3. Click the Clicky toolbar icon, open Settings in the panel and paste this site's address.
